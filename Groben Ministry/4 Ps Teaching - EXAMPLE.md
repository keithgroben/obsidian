# EXAMPLE — The Curriculum Architecture

*Source: Notion — https://www.notion.so/3406abe00ba4800b8661dba6df629f37 (in 4 Ps Teaching database)*

## The Curriculum Architecture

The Lesson DNA: **Problem → Principle → Process → Practice + Bridge**

Every single lesson, module, and micro course follows this same pattern. This is non-negotiable.
This is what makes the curriculum teachable, recordable, and repeatable without becoming a burden.

**Problem**
Name the pain in their words. They feel seen. They lean in. The problem is always stated FIRST, before any teaching. This is the "How this applies if you are an X" pattern. The problem gets named so they feel seen, THEN you teach.

**Principle**
Teach the ONE concept that solves it. Not five. One. Then land the contextual bridge for each avatar.

**Process**
Show the steps. This is where screen recordings live. "Here's how I do it. Watch."

**Practice**
Give them something to DO. An exercise, a template to fill in, a system to build. They walk away with an output, not just an idea.

**Bridge**
After the principle, land it in each avatar's reality:
- "If you're running a local business..."
- "If you're pastoring (and running a business)..."
- "If you're coaching or selling digital products..."

Same lesson. Three applications. The person self-selects. They hear their version and tune in harder.

## The Content Hierarchy

- A **lesson** is one 4P+Bridge cycle. 10–15 minutes. One screen recording. One downloadable template or exercise.
- A **micro course** is 3–5 lessons. Solves ONE specific problem. Finishable in a sitting.
- A **full course** is 4–6 micro courses bundled with a through-line.
- A **coaching program** is the full course plus live calls and accountability. (Future tier.)

## The Learning Ladder: Think → Map → Build → Connect

This is the progression students move through across the full curriculum:

- **Rung 1: Think in Systems** — See your business as a set of processes. Dean Jackson's Before/During/After. Break each phase into parts.
- **Rung 2: Map a Process** — Take ONE process and break it down. Objective vs. subjective. Inputs and outputs. Structured thinking without ever saying "structured data."
- **Rung 3: Build It in a Tool** — NOW they're ready for Notion, Claude Projects, spreadsheets. The micro courses live here. Each one takes a mapped process and implements it.
- **Rung 4: Connect the Pieces** — Multiple systems talking to each other. Automation thinking. Notion integrations, Zapier, Claude. They graduate from "I have a board" to "I have an operating system."
