# Deployment Overview

Deployment in hostile environments where failure means imprisonment or death. Success depends on community trust, operator training, and OpSec—not just technical perfection.

## Timeline Summary

**Total Duration:** 8 weeks from planning to operational network

**Phase Breakdown:**
- **Weeks 1-4:** Pre-Deployment (community engagement, planning, procurement)
- **Weeks 5-6:** Installation (relay, hub, and bridge nodes)
- **Weeks 7-8:** Training (operators and users)
- **Ongoing:** Operations and maintenance

## Critical Success Factors

### Community Trust
Establish relationships with local leadership before deploying hardware. Network acceptance depends on community buy-in, not just technical excellence.

### Operator Training
6-9 local operators trained intensively for 2 weeks. They must understand both technical operations and security model explanation to users.

### Operational Security
All deployment activities assume active surveillance. Covert procurement, hidden nodes, compartmentalized knowledge, and plausible deniability built into every step.

### Home Base Support
Remote technical team provides 24/7 support for field operators: software maintenance, monitoring, troubleshooting, and security analysis.

## Deployment Phases

### Pre-Deployment (Weeks 1-4)
**Focus:** Foundation and preparation
- Community engagement and trust building
- Coverage mapping and node placement planning
- Covert hardware procurement across multiple vendors
- Operator selection through community nomination
- Security risk assessment

**See:** [10-01-deployment-pre-planning](10-01-deployment-pre-planning.md)

### Installation (Weeks 5-6)
**Focus:** Physical infrastructure deployment
- 47 relay nodes (Raspberry Pi + WiFi amplification)
- 3 hub nodes (high-traffic locations)
- 3 bridge nodes (satellite internet gateways)
- End-to-end connectivity testing
- Coverage verification

**See:** [10-02-deployment-installation](10-02-deployment-installation.md)

### Training (Weeks 7-8)
**Focus:** Operator and user capability building
- 2-week intensive operator training (14 days)
- Network basics, hands-on maintenance, OpSec protocols
- User support training: explaining security model
- 2-hour user training sessions (groups of 10-20)
- Wallet privacy education and panic mode practice

**See:** [10-03-deployment-training](10-03-deployment-training.md)

### Operations (Ongoing)
**Focus:** Sustainable network maintenance
- Daily monitoring, weekly inspections, monthly maintenance
- User support and troubleshooting
- Hardware replacement and upgrades
- Budget management and reporting
- 24/7 home base technical support

**See:** [10-04-deployment-operations](10-04-deployment-operations.md)

## Budget Overview

**Infrastructure (One-Time):** ~$14,000 for 50-node network  
**Annual Operations:** ~$113k-164k (includes operator salaries, Starlink, hardware replacement, home base team)

**Funding Model:** Alliance of businesses and ministries with multi-year commitment secured before deployment.

## Success Criteria

**Deployment Phase:**
- Network operational within 8 weeks
- Zero security incidents during installation
- All operators trained and confident
- 100+ users onboarded

**Operations (First 3 Months):**
- 95%+ relay node uptime
- Message delivery <5 seconds (3-hop average)
- 200+ active users
- 90%+ user retention
- Operators handle 80% issues independently
- Zero critical security compromises
