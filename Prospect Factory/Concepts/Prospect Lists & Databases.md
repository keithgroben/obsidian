# Prospect Lists & Databases

In Ted Stevenot's system, the prospect list is the raw material of the whole prospecting operation, and a database is the machine that keeps that material organized, current, and actionable. Building a list starts upstream with a clearly defined target market, then pulls from primary sources into a primary list you actually own and control. From there the work is about structure: sorting records so they're usable in the field. An ascending sort and a ZIP code sort aren't busywork — they group prospects geographically so calling and routing follow an efficient pattern instead of bouncing across town.

The database is where a static list becomes a living asset. Stevenot distinguishes purpose-built layers — a list scrubbing database to clean and de-duplicate, a mailing database for outreach, a client service database for accounts already won, and ultimately a CRM that ties contact history, status, and follow-up into one record. Each serves a different stage of the relationship.

What ties it all together is discipline. Lists decay the moment they're built, so list scrubbing and routine updating are ongoing obligations, not one-time setup. A clean, well-sorted, well-maintained database is what lets data actually improve prospecting — turning a pile of names into a qualified, workable pipeline.
