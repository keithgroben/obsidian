# 2.5 "OK" Codes

"OK" Codes are numerical codes that categorize and activate the qualifying data you gather from prospects. These codes help arrange and direct future follow-up with prospects based on the outcome of calls or other interactions with prospects.

## Why the Name "OK" Code?

The "OK" Code gets its name from my early prospecting career. When I first started out, 100% of the Finished Leads I generated came from the phone. As time went by, I noticed a certain percentage of the prospects I talked to would ask if I could "just send something" through the mail.

At first, I had nothing to send. Later, my wife and I created a simple self-mailing piece for this purpose. It ended up paying for itself almost immediately. Somehow, it later occurred to me that instead of waiting for prospects to ask me to send something, I should begin proactively asking them if it would be "OK" to do so.

On the phone, and especially when I heard that a prospect was unavailable I would to ask,

> "Would it be OK to send him (or her) something through the mail?"

To manage "Yes" responses, I started keeping a paper list by my phone each day. Eventually, this list became a pre-printed form with a column labeled "OK." A checkmark in the column meant I would drop that person something in the mail after finishing calls that day.

When fax machines came on the scene, I started asking for similar permission to send faxes to prospects. To reassure people I wouldn't burn up a ton of their fax paper, I promised to condense what I would send down to "one page."

In time, my new fallback line for unavailable prospects became,

> "Would it be OK if I sent him (or her) a one-page fax?"

The stipulation that the message be one-page in size forced me to figure out how to create an effective one-page marketing letter. Hence, the "One-Pager" was born.

## Operational Codes and Opportunity Codes

There are two types of "OK" Codes – Operational Codes and Opportunity Codes.

- **Operational Codes** are used to keep track of standard recurring responses.
- **Opportunity Codes** are used to flag prospects who reveal themselves to be candidates for special opportunities.

## Operational Codes

Say you call a prospect and you get voicemail. This is a typical and recurring call result. An Operational Code makes it easy to codify and track what happened. You can easily "query" or filter your database in the future if you wish to re-call such prospects because you missed reaching them.

Consider the following eight Operational "OK" Codes and what they mean. Because they recur so often, you may wish to read over these code definitions a few times to be certain you really have them down.

### "OK" Code "1" - Not Interested Currently

An "OK" Code "1" is a prospect you called who is not interested currently.

This is a prospect whose overall status did not change as a result of the call. For example, if this is the first time you are calling through a primary list, you would assign a code "1" to a prospect you talked to whom,

- You were unable to upgrade or downgrade (i.e. upgrade to the [[Plus List]] or downgrade as a disqualified prospect).
- Needed no current follow-up. (i.e. you decided not to send this prospect a One-Pager and this prospect did not become a Finished Lead.)

The best example of a "1," is a prospect you call who gives you no information other than to say that he or she is not interested at this time. This type of prospect is the most basic prospect. Such prospects stay on their current list (whether a primary list or a Plus List) until they are designated otherwise (i.e. either upgraded or downgraded).

### "OK" Code "2" - Send One-Pager by Mail

An "OK" Code "2" is a prospect who was called today, and the decision was made to send him or her a One-Pager by mail.

This prospect may not have been available when he or she was called. So, the question was asked,

> "Would it be OK to send him (or her) something?"

At the end of a phoning day, I query my database for all the "2" prospects from that day (i.e. current "OK" field = 2 and current "Last Call" date = today). I then use a mail-merge utility to print envelopes for all the "2" prospects in one print job. I stuff the finished envelopes with pre-printed One-Pagers and mail them the same day.

### "OK" Code "3" - Answering Machine, Busy Signal

An "OK" Code "3" designates a prospect you called, but you did not contact.

With this type of call, you did not have an opportunity to ask about current interest, nor did you get to ask this prospect (or his or her call screener) about the possibility of sending something. Typical examples are answering machines, unattended voicemail, and busy signals.

When I finish a calling through my list, I sometimes query or filter out the number "3" prospects that occurred and give them all one more chance to be called. The first time I tried this, I wasn't optimistic about how many of the number "3" prospects I would contact, but to my surprise it turned out they were a productive group to call one more time.

### "OK" Code "4" - Disconnected Number

An "OK" Code "4" is a disconnected or a changed number.

Usually a disconnected number means the prospect is a disqualified prospect. But, because sometimes phone numbers get changed, a disconnected number may not always mean the prospect is disqualified for sure. Therefore, I keep track of these prospects, and I double-check their status when I update my list.

A number "4" prospect can also be a prospect who has had contact information (i.e. phone number, address, company name, etc.) changed to such a degree, I feel this information should be carefully double-checked during the next list update.

### "OK" Code "5" - Send Immediate Email

An "OK" Code "5" represents a prospect to whom an "immediate" email was sent.

This is a prospect talked to directly who asked for more information to be sent by email that day. Such an email is sent using the CRM email system immediately upon request. I have several email templates saved in my CRM for this purpose. All thank the prospect for taking my call and most include an attached One-Pager.

In addition to or in lieu of a One-Pager, I may also include link to a blog article, landing page, and/or contact form on my website. In the right circumstances, and assuming the prospect clearly understands and authorizes it, a custom code could be applied here that triggers an automated email drip follow-up campaign.

### "OK" Code "6" - Finished Lead

An "OK" Code "6" is a currently interested, Finished Lead.

Here, I will likely add information into the prospect's notes field during the call (i.e. a standard field in nearly every CRM) that will allow me to get back to him or her with something meaningful such as a quote or proposal.

I query my database for number "6" prospects at the end of each phoning day and forward them on to the next level of follow-up.

### "OK" Code "7" - Disqualified Prospect

An "OK" Code "7" is a disqualified prospect.

This is a prospect who revealed himself or herself to be a non-viable prospect. I stop calling prospects once they have been designated with a code of "7." During a list update, I will remove these prospects from my primary and Plus Lists. I keep a disqualified-prospect list saved as a part of my [[List Scrubbing]] database to help me filter out such names in the future.

### "OK" Code "8" - Take Off List

An "OK" Code "8" is a prospect who asks to be placed on your in-house Do-Not-Call list.

An "OK" Code "8" designates a prospect who has requested his or her name be taken off the call list and/or not be called. I take this prospect's name off my phone lists and immediately add it to my company specific "Do-Not-Call" list. (See "Appendix A" on Telemarketing Legislation.)

Now that you've read these Operational Code definitions once, I highly recommend that you go back and read through them again to be sure you really have them down.

## Opportunity Codes

As you call and interact with your prospects, it is important to listen carefully to what prospects say and keep track of what you hear. This remains true even when a prospect says, "Not interested." or passes on an initial call or pitch. In such instances, prospects will often reveal additional information that can signal potential future opportunities. But you must be on the lookout for such signals in order to take advantage of them.

At one point in my career, I got the idea to spend a day calling and catalog every possible response I heard from prospects. I sat down with a list of several hundred general prospects and gave it a go. By the end of the day, I had noticed about 10 recurring responses.

In my office, I have a chalkboard painted on one wall. I listed the responses on the wall. I left the list there for days and thought more about them. I asked myself, "What are these people really saying? What could I have said in response? Is there a workable way to turn any of these negatives into positives?"

It soon became clear that many responses indicated opportunities for products that were *not* the subject of the initial call. Further, it became clear that by sending One-Pagers relevant to these opportunities by mail, I could favorably re-contact many of these individuals to open doors for new business.

Because I had done so well with the use of operational types of "OK" codes, I decided to create a similar system for the more specialized responses I was hearing. Today, when I hear certain replies from prospects, I can instantly assign them an Opportunity Code number. I keep these codes in a separate set of data fields so I can filter them from the database for future outreach.

## Creating Opportunity Codes

Think about your business. What kinds of responses do you regularly hear from prospects? Especially think about the responses that at first appear to be negative or dead-end. Some may be so. But others may merely be a veneer behind which new opportunities are hiding.

The easiest way to ferret out these opportunities is as I described above. Grab a sheet of paper and start listing the responses you repeatedly hear. Assign numbers to each response. I use double digits "35", "36", "40", "41" (i.e. no joke...these are legit actual code numbers I use as of this writing).

Review the list regularly and ask yourself, "What value is hidden here? How can I turn these responses into other opportunities?" In time, it is likely you will find a whole new set of doors to open for your business.

## "OK" Codes and Data Management

Note that "OK" Codes are "numbers" (i.e. 1, 2, 3, 4, 28, 30, 32, etc.) for a reason. While initially it may seem difficult to remember what an "OK" Code "2" or an "OK" Code "4" is, it is well worth the effort required to learn and apply the numbers.

Not only does assigning code numbers for recurring responses help focus your efforts, it makes data management easier. Numbers query more rapidly and greatly reduce the chance of errors. By contrast, using words such as "immediate email" or "disqualified prospect," if mistyped or contextually scrambled, make a mess of future data queries.

## Filtering or Querying by "OK" Code

At the end of a call-cycle, if you want to see all the "OK" Code "3" (or any other code number) prospects on your list that occurred during the current call-cycle, you can run a query or filter seeking all the prospects having,

Current "OK" field = "3"

When you run this filter, the "OK" Code "3" listings from the current call-cycle instantly appear on your computer screen.

The same kinds of queries or filters can be run with any "OK" Code and in relation to any "last call" dates from any prior call-cycle. So, you can find out,

- How many new letters you sent as a result of a particular call-cycle.
- How many finished leads you found by phone.
- How many listings became disqualified.
- How many listings had no change in status, etc.

All you must do is run the appropriate query or filter and – Viola! - the information you are looking for appears.

## Daily Follow-Up Using "OK" Codes and "Last Call" Dates

Daily follow-up activities are managed through queries that run on a combination of the current "OK" field and the current "Last Call" field. If, for example, at the end of a day of calling, you want to know which prospects need to have a One-Pager sent to them by mail, you can run a query or filter seeking,

- Current "OK" field = "2" (Send One-Pager by Mail)
- Current "Last Call" field = today's date.

In an instant, the list you are looking for appears.

If, at the end of a day of calling, you want to know which prospects became Finished Leads, you can run a query or filter seeking,

- Current "OK" field = "6" (Finished Lead)
- Current "Last Call" field = today's date.

And, again, the list you are looking for appears.

Being able to conveniently gather groups of prospects that require the same type of follow-up makes following up easier. It also ensures that along with being able to easily communicate with many prospects, you will be able to follow-up with those prospects in an organized and timely manner.

## Key Terms to Remember

- **"OK" Code "1"** – Not Interested Currently
- **"OK" Code "2"** – Send One-Pager by Mail
- **"OK" Code "3"** – Answering Machine, Busy Signal
- **"OK" Code "4"** – Disconnected Number
- **"OK" Code "5"** – Send Immediate Email
- **"OK" Code "6"** – Finished Lead
- **"OK" Code "7"** – Disqualified Prospect
- **"OK" Code "8"** – Take Off List

**Operational "OK" Codes** – Codes used to keep track of standard recurring responses.

**Opportunity "OK" Codes** – Codes used to tag prospects who have revealed themselves to be candidates for special opportunities.
