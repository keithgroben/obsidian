## Prompt Template

I need you to adapt this business description for multiple social media platforms. Maintain the core message, brand voice, and key differentiators while respecting each platform's character limits and user context.

**BUSINESS INFO:**
- Name: [Business Name]
- Industry: [Industry]
- Master Description (750 chars): [Their pillar content]
- Primary CTA: [Their CTA]
- Location: [City]

**PLATFORMS NEEDED:** [Their selections]

For each platform, provide:
1. Optimized description (within character limit)
2. Character count used

## Platform Specs

- **Google Business Profile:** 750 chars (use as-is or refine)
- **LinkedIn Overview:** 2000 chars (expand with detail)
- **LinkedIn Tagline:** 120 chars (positioning statement)
- **YouTube Description:** 1000 chars (video content angle)
- **Pinterest About:** 500 chars (visual/inspirational)
- **Facebook About:** 255 chars (concise value prop)
- **Instagram/Threads Bio:** 150 chars (punchy + emoji-friendly)
- **TikTok Bio:** 80 chars (ultra-short + CTA)

**Maintain:** brand voice, differentiators, location, key services, CTA

---

## Character Limit Enforcement (CRITICAL)

BEFORE writing each platform description:
1. Draft the content
2. Count total characters (including spaces and punctuation)
3. If OVER limit, cut content until UNDER limit
4. Show final count as: "Character count: X/[LIMIT]"

**HARD LIMITS (NEVER EXCEED):**
- Google Business Profile: 750 max
- LinkedIn Overview: 2,000 max
- LinkedIn Tagline: 120 max
- YouTube: 1,000 max
- Pinterest: 500 max
- Facebook: 255 max
- Instagram/Threads: 150 max
- TikTok: 80 max

## Cutting Strategy (in order)
1. Remove redundant phrases
2. Shorten verbose descriptions
3. Cut less critical services/details
4. Use abbreviations where appropriate (& instead of "and")
5. Remove emojis if still over (except Instagram/TikTok)

⚠️ ALWAYS verify character count before outputting. Being under limit is OK. Being over is NOT.
