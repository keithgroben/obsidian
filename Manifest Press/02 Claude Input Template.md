## Tips

**Be Honest in Assessments** — Don't rate "Strong" if vague.
**Extract Key Elements** — Pull client names, numbers, specific phrases.
**Provide Context** — Note when interview expanded on form; explain contradictions.
**Reference Quality** — "Strong" = use directly; "Weak" = flag.
**Custom Instructions** — Add client preferences and focus areas.
