# Keith Groben Life Timeline Project - Instructions

## Project Overview
This project aims to organize Keith Groben's life events, career milestones, and personal history into a comprehensive timeline that can be used across multiple media platforms (LinkedIn, podcasts, etc.) to help audiences connect with his background and journey.

## Document Purpose
- Extract key life events from transcripts and documents
- Create chronological timeline with dates (month/year when available)
- Track location information for each period
- Document employment/career positions
- Record family status (marital status, children)
- Organize information for storytelling across various media formats

## Timeline Data Points to Track
For each life period/event, capture:
1. **Date**: Month and Year (when available)
2. **Location**: City, State where Keith was living
3. **Employment**: Job title, company, role description
4. **Family Status**: 
   - Marital status (single, engaged, married)
   - Children (names, ages if mentioned)
5. **Key Events**: Significant milestones, achievements, transitions
6. **Context**: Additional relevant information for storytelling

## Document Structure
- **Project Instructions** (this document): Guidelines and methodology
- **Timeline Master Document**: Chronological overview of all life events
- **Individual Transcript Summaries**: Titled summaries of each transcript added to project knowledge
- **Supporting Documents**: Resume, portfolio, bio for reference

## Workflow
1. Process each transcript individually
2. Create titled summary for project knowledge
3. Extract timeline-relevant information
4. Add to master timeline with all tracking data
5. Cross-reference with existing documents for accuracy and completion

## Output Formats
Timeline will be structured to support:
- LinkedIn narrative posts
- Podcast storytelling
- Professional portfolio presentations
- Media interviews and profiles

## Current Source Materials
- Complete Marketing & Sales Experience Portfolio
- Professional Resume
- Professional Bio
- Voice transcripts (to be processed)

## Notes
- Prioritize accuracy over speed
- Flag any conflicting dates or information for review
- Maintain conversational, authentic tone suitable for storytelling
- Focus on human elements that create connection with audience
